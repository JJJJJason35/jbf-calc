# QT延时计算器

一个纯前端的加班费计算工具。根据考勤系统的班次与打卡数据，自动识别周末加班与工作日晚加班，并按分钟精确计费。

## 特性

- **智能识别加班类型**：依据班次字段判定，而非机械地按周六周日计算
  - 班次为 `休息` 且有打卡记录 → 周末加班
  - 班次含 `深圳/佛山/桂林`（正常班）且末次打卡晚于 19:00 → 工作日晚加班
- **自动排除调休补班**：周末若被安排为正常班（调休补班），不会被误判为周末加班
- **延时餐费补贴二次复核**：仅当 `延时餐费补贴次数 = 1` 时才计入当日加班
- **考勤异常标注**：识别 `ISEXCEPTION` 字段，异常日期在明细中标出
- **明细按需显示**：仅展示有考勤异常或有加班的日期，正常上下班日自动隐藏
- **精确到分钟计费**

## 计费规则

| 加班类型 | 单价 |
| --- | --- |
| 周末加班 | 30 元/小时 |
| 工作日晚加班 | 20 元/小时 |

计费精确到分钟，分钟数按向下取整计算。

## 使用方法

1. 用 Chrome 打开 QHR 个人考勤查询页面，按 `F12` 打开开发者工具，切换到 `Network` 面板
2. 触发考勤查询，找到 `alist!2CXvv_JQ9M03QhX8PGCgxw.220302` 请求，复制其 JSON 值粘贴到**打卡数据**输入框
3. 找到 `alist!G8_TRwtFegd0QeO2BfN6kg.220398` 请求，复制其 JSON 值粘贴到**班次/餐补数据**输入框
4. 点击「计算」查看结果

支持快捷键 `Ctrl / Cmd + Enter` 触发计算。

## 数据来源字段

工具从接口返回的 JSON 中读取以下字段：

| 字段 | 含义 |
| --- | --- |
| `CARDTIME` | 打卡时间 |
| `SHIFTTERM` | 打卡所属日期 |
| `TERM` | 班次记录日期 |
| `SHIFT` | 班次名称 |
| `C018_1` | 延时餐费补贴次数 |
| `ISEXCEPTION` | 是否考勤异常 |
| `TITLE` | 员工姓名（用于问候语） |

## 隐私说明

本工具为纯静态单文件前端应用，**所有计算均在浏览器本地完成**，不包含任何数据上传逻辑，不依赖任何外部 CDN 资源。可完全离线使用，直接双击 `index.html` 即可运行。

## 本地运行

```bash
# 直接用浏览器打开
open index.html   # macOS
start index.html  # Windows
```

## 部署到 Cloudflare Pages

本项目为纯静态资源，**无构建步骤**。Cloudflare Pages 构建配置如下：

| 配置项 | 值 |
| --- | --- |
| Framework preset | `None` |
| Build command | 留空 |
| Build output directory | `/` |

通过 Git 集成后，每次向主分支推送都会自动触发重新部署。
